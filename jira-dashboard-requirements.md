# Jira Sprint Progress Dashboard Requirements

## Goal

Provide the EPAM L&D Team and stakeholders with a concise view of progress during the active sprint.

## Platform and audience

- **Platform:** Native Jira Cloud dashboard.
- **Primary audience:** Delivery team and stakeholders.
- **Sharing:** Available to project users.
- **Refresh:** Every 15 minutes.

## Scope and metrics

- Focus on the active sprint only.
- Measure progress using story points.
- Show:
  - Completed versus remaining work.
  - Sprint burndown.
  - Scope added or removed during the sprint.
  - Work by assignee.
  - Issue status breakdown.

## Project and board

- **Team:** EPAM L&D Team.
- **Jira project:** Not yet identified; the project key or link is needed.
- **Scrum board:** Not yet identified. Reuse the team's existing Scrum board if available. Do not create a new board unless no suitable board exists and its project scope is confirmed.

## Open items

1. Identify the Jira project and confirm its key or URL.
2. Locate the team's Scrum board and confirm it represents the intended sprint work.
3. Confirm that the selected Jira gadgets support the requested metrics and refresh interval in this Jira Cloud instance.
